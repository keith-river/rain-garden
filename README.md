# 私の雨庭デザイン — Rain Garden Designer

> 言葉の選択で、素敵な雨庭デザイン

大学オープンキャンパスのデモ展示用に制作した、インタラクティブな雨庭体験アプリです。  
タロットカード風の言葉選びを通じて、あなただけの雨庭が3Dで生成されます。

---

## デモの動かし方

**インストール不要。`rain_garden.html` を単体でブラウザで開くだけで動作します。**

```
1. rain_garden.html をダウンロード
2. Chrome / Edge / Firefox などで開く
3. 「はじめる」ボタンをクリック
```

推奨環境: デスクトップブラウザ（Chrome / Edge / Safari 最新版）

---

## アプリの概要

### 操作フロー

| ステップ | 内容 |
|---------|------|
| ①カード選択 | 4ターン × 4枚のカードから直感で1枚ずつ選ぶ |
| ②3D生成 | 選んだ言葉のイメージが雨庭の部材（石・池・松・低木など）に変換される |
| ③鑑賞 | マウスドラッグで視点回転、スクロールでズーム |
| ④編集 | 「✏ 配置を編集」で部材のドラッグ移動・リサイズが可能 |

### 選択カテゴリー

| ターン | カード |
|--------|--------|
| 第1ターン（タロット） | 月 / 星 / 太陽 / 塔 |
| 第2ターン（色） | 青 / 緑 / 白 / 橙 |
| 第3ターン（動物） | 鹿 / 魚 / 鷹 / 蝶 |
| 第4ターン（植物） | 松 / 竹 / 桜 / 苔 |

### 生成される部材

石・池・鹿威し（しし脅し）・盆栽・松・広葉樹・低木・芝

---

## 雨庭（レインガーデン）とは

ゲリラ豪雨による都市型洪水を緩和するグリーンインフラの一つ。  
庭に浅い窪みを設け、植物と土壌の力で雨水を地中にゆっくり浸透させる仕組みです。

このアプリは「雨庭という選択肢を知ってもらう」ことを目的とした実験的プロトタイプです。
