# あなたの庭が街を守る ― ゲリラ豪雨と「雨庭」という選択

## はじめに

「昨日、あの道路また冠水してたよ」

最近、こんな会話が増えていませんか。

2010年代以降、いわゆる「ゲリラ豪雨」の発生頻度は明らかに増加しています。気象庁のデータによれば、1時間降水量50mm以上の豪雨は、30年前と比べて約1.4倍に増加しました。都市部では、地表のほとんどがアスファルトやコンクリートで覆われているため、雨水が地中に染み込まず、一気に排水路へと流れ込みます。その結果、下水道の処理能力を瞬時に超え、低地や交差点が突然冠水するという事態が繰り返されています。

これは「行政に任せるべき問題」なのでしょうか。もちろん、インフラ整備は行政の責任です。でも、私たちひとりひとりが「自分の庭」でできることは、本当にゼロなのでしょうか。

## なぜこのアプリを作ったのか

ある住宅街を歩いていたとき、あることに気づきました。多くの家の庭が、砂利敷きかコンクリートで固められています。見た目はきれいだし、管理も楽。でも、その庭は「雨水の逃げ場」を奪っているのかもしれません。

「雨庭（レインガーデン）」という言葉を知っていますか。庭に浅い窪みを設け、植物や土の力を借りて雨水を地下へゆっくり浸透させる、小さな治水の仕組みです。欧米では一般住宅でも広く普及しており、日本でも国土交通省が「グリーンインフラ」の一つとして普及を促進しています。

ただ、「雨庭を設けましょう」と言われても、なかなかピンとこない。どんなものか、自分の庭に合うのか、想像しにくいのが実情です。

そこで考えました。**まず「知ること」ではなく、「体験してみること」から始められないか。** 遊びながら、自分ごととして雨庭を考えてみるきっかけを作れないか——。

そうして生まれたのが、このアプリです。

## どんなアプリか

**「私の雨庭デザイン（rain garden）」** は、言葉を選ぶだけで、自分だけの雨庭デザインが3Dで生成されるシングルページアプリケーション（SPA）です。

タロットカードのように、4つのカテゴリー（タロットの言葉・色・動物・植物）から、それぞれ4枚のカードが提示されます。直感で1枚ずつ選んでいくだけで、あなたの「感覚」が反映された雨庭のデザインが完成します。

<!-- ここにアプリのスクリーンショットを挿入 -->

選択が完了すると、石・池・鹿威し・盆栽・松・広葉樹・低木といった部材が、選んだ言葉のイメージに応じて配置された3Dの庭が現れます。部材にマウスを乗せると、なぜその部材が選ばれたかと、雨庭における役割が表示されます。また、部材はドラッグで移動でき、ハンドルをドラッグしてリサイズすることもできます。

「占いみたいで面白い」という感覚でかまいません。その先に、雨庭という概念が残ってくれれば十分です。

## 実際に触ってみる

**GitHub:** https://github.com/keith-river/rain-garden

リポジトリから `rain_garden.html` を単体でダウンロードし、ブラウザで開くだけで動作します。インストール不要、サーバー不要のSPAです。

**基本的な操作手順：**

1. 「はじめる」ボタンをクリック
2. 4ターン×4枚のカードから、直感で1枚ずつ選ぶ
3. 完成した3D雨庭を鑑賞する（マウスドラッグで視点回転、スクロールでズーム）
4. 部材にマウスを乗せると、解説が表示される
5. 「✏ 配置を編集」ボタンで、部材の移動・リサイズが可能

## 触ってみて考えてほしいこと

アプリを体験した後、少しだけ立ち止まって考えてみてください。

**「私の家の庭（またはベランダ）は、今、雨とどんな関係にあるだろう？」**

雨が降ったとき、あなたの家の敷地内で、雨水はどこへ行くでしょうか。コンクリートやタイルの上を流れ、側溝へ。そのまま排水路に合流し、雨が強ければ溢れる——。

雨庭は、その流れを少しだけ変える試みです。庭の一角に浅い窪みを作り、砂利や植物で覆うだけで、雨水の一部が地面に吸収されていきます。設置費用は規模によって異なりますが、小さなものは数万円から始められるとも言われています。

ひとつの庭が変わっても、街全体への影響は限定的かもしれません。でも、100軒の庭が変われば？1000軒では？

気候変動対策は、大規模なインフラ整備だけでは間に合わない時代に入っています。個人の庭という「小さな単位」から始まる変化の積み重ねが、ゲリラ豪雨に強い街づくりの一端を担う可能性があります。

このアプリは、その「可能性」を想像するための道具として作りました。

## 技術メモ

HTML5とJavaScriptのみで動作するSPAとして実装。3D描画にはThree.js（r128）を使用し、外部サーバー不要の単一ファイルとして配布できます。部材の配置・リサイズはカスタム実装のオービットコントロールと地面平面へのレイキャストで実現しています。

```javascript
// 地面平面へのレイキャストで3D空間上の座標を取得
function groundPoint() {
  const pt = new THREE.Vector3();
  raycaster.setFromCamera(mouse, camera);
  raycaster.ray.intersectPlane(groundPl, pt);
  return pt;
}
```

すべての実装は生成AIとの対話を通じて行い、コードの全文掲載はGitHubをご参照ください。

## 生成AI活用について

このアプリは、**課題設定と設計思想は筆者が行い、実装に生成AIを活用**しました。

「雨庭という社会課題を、タロットカードのような直感的な操作で体験できるアプリにしたい」という方向性は筆者が設定し、UI設計・ゲームフロー・言葉と庭要素のマッピング構造といった設計判断も筆者が行いました。その上で、Three.jsを用いた3Dシーンの実装、インタラクション処理、CSSアニメーションなどの具体的なコーディングを生成AIとの対話を通じて進め、動作確認・レビュー・修正のサイクルを繰り返しました。最終的な品質チェックと公開判断は筆者が行っています。

生成AIは「速く書けるツール」ではなく「考えを形にする対話の相手」として活用しました。試作の速度が上がった分、「何のために作るか」という問いに時間をかけられるようになったと感じています。
